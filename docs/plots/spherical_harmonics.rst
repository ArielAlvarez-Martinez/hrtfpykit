Spherical-harmonic plots
========================

The plot package includes functions for visualizing spherical-harmonic
reconstruction results.

Import
------

.. code-block:: python

   from hrtfpykit.plots import (
       plot_sht_reconstruction_comparison,
       plot_sht_reconstruction_error,
   )
